方法论与局限

Read this before quoting these numbers. This run used the deterministic replay adapter -- a scripted agent, not a language model. It demonstrates that the mechanism works: skills and pitfalls are distilled, retrieved, and measurably improve outcome, steps, and tokens. It says nothing about how a specific frontier model behaves. For that, run with --provider openai or --provider anthropic.
两种学习信号的贡献是可分离的：成功率主要由 Pitfall（失败教训）驱动， 因为被警告过的 agent 会绕开已知陷阱；步数与 Token主要由 Skill（成功技能）驱动， 因为蒸馏出的函数把多步推导压缩成一次调用。若只升成功率而步数不降，说明 pitfall 生效而 skill 未生效 —— 这比笼统的"变好了"更有诊断价值。
